## ٣) قواعد أثناء التحول

1. كل مرحلة تنتهي بـ: **lint + tsc + build + smoke** ثم commit ثم نسخة احتياطية.
2. أي مرحلة فيها تغيير schema: **نسخ احتياطي أولًا** + تجربة استرجاع.
3. الميغراشن: `--create-only` ثم `deploy` (مفيش `migrate dev` تفاعلي).
4. التفعيل التدريجي لعزل المستأجرين: تشغيل `TENANT_ISOLATION=true` بعد ما كل استعلامات الوحدة تمشي من `lib/tenant.ts`.
5. السجلات المالية والتاريخية: لا حذف — إلغاء/أرشفة فقط، مع AuditLog.
