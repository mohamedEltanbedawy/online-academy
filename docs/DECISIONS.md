# سجل القرارات — Family OS
### Decision Log — القرارات المهمة وسبب اختيارها

> كل قرار مهم في المشروع يُكتب هنا قبل الشغل عليه — حسب قواعد الشغل.

## القرارات المعتمدة

| # | القرار | الاختيار | ليه؟ |
|---|---|---|---|
| 1 | شكل المستأجرين | **كل عائلة مستأجر (Tenant) مستقل فورًا** — المؤسسات مستأجر من نوع INSTITUTION/PROVIDER | الأصح للتوسع؛ العائلة هي نواة النظام وبياناتها معزولة وحرة |
| 2 | تمثيل الإنسان | كل إنسان = **Person (توأم رقمي)** مع حساب دخول اختياري | كل الوحدات (تعليم/صحة/ذاكرة) تشترك في نفس الكيان |
| 3 | إدارة الـ AI | **من لوحة الإدارة**: إضافة/إزالة/تبديل مقدمي النماذج (بما فيها Ollama محليًا) | حرية وخصوصية + توفير تكلفة |
| 4 | النموذج اللغوي الافتراضي | **Gemini** | متاح وسريع ويدعم العربية |
| 5 | التضمين والبحث | **pgvector** في Postgres | بدون إضافات ثقيلة، مع الداتابيز الحالية |
| 6 | قناة الإشعارات الأساسية | **Telegram** (بوت واحد + كود ربط لكل عائلة) | متاحة للجميع وأسهل للعائلات |
| 7 | ترتيب التجربة (Pilot) | لوحة الأسرة + التقويم/الخطة اليومية → الصحة → المساعد الذكي → ذاكرة العائلة → المخطط الذكي → الروبوت | يبدأ بما يجعل العائلة تستخدم النظام يوميًا |
| 8 | التعليم ضمن Family OS | التعليم يفضل **وحدة أساسية** لكن العائلة هي المركز | نفس المنصة، مركزية أكبر |
| 9 | اللغات | **عربي + إنجليزي من اليوم الأول** | الجمهور المستهدف ثنائي اللغة |
| 10 | حجم التجربة | **3–7 عائلات** | تجربة واقعية بدون مجازفة |
| 11 | طريقة الترقية | **إضافية فقط + backfill + feature flags** — العزل عبر DAL تدريجيًا | لا تعطّل النظام الشغال حاليًا |
| 12 | نشر السنة الأولى | **سيرفر Docker ذاتي الاستضافة (Ubuntu)** بجهاز واحد، جاهز للكلاود | تكلفة منخفضة وتحكم كامل في البداية |
| 13 | التخزين | **MinIO اختياري** لاحقًا (رفع الملفات) | محلي أولًا ثم قابل للنقل |

## قرارات قيد النقاش

- سعر اشتراك المكتبة المسجلة ونسبة المدرس منه.
- رسوم الأنشطة: داخل الاشتراك أم منفصلة؟
- مناهج الإنجليزي المحددة (Oxford/Cambridge/Jolly Phonics).
- تفاصيل صحة الطفل: من يسجل (ولي الأمر أم الأخصائي) ومدى المشاركة.
